  <behavior>

    - errors.Is(err, compiler.ErrMaxErrors) returns true when MaxErrors limit was hit
    - errors.Is(err, compiler.ErrDuplicateIdent) returns true when duplicate identifier error occurred
    - errors.Is(err, compiler.ErrAugmentNotFound) returns true when augment target unresolved
    - Compiler with zero errors returns nil from Compile() — errors.Join of empty slice is nil
  </behavior>
  <action>
1. Add exported sentinel vars after the import block in compiler/compiler.go:
```go
var (
    ErrCircularTypedef  = errors.New("circular typedef")
    ErrCircularUses     = errors.New("circular dependency in uses")
    ErrAugmentNotFound  = errors.New("augment target not found")
    ErrDuplicateIdent   = errors.New("duplicate identifier")
    ErrListMissingKey   = errors.New("list key error")
    ErrConfigBoundary   = errors.New("config boundary violation")
    ErrInvalidDefault   = errors.New("invalid default value")
    ErrMandatoryDefault = errors.New("mandatory leaf with default")
    ErrTypeRestriction  = errors.New("invalid type restriction")
    ErrIdentityrefBase  = errors.New("invalid identityref base")
    ErrXPathSyntax      = errors.New("xpath syntax error")
    ErrMaxErrors        = errors.New("compilation stopped: too many errors")
)
```

2. Change `c.errors []string` field to `c.errors []error` in the Compiler struct.

3. Update `New()` initializer: `errors: make([]error, 0)`.

4. Replace the `addError(msg string)` body with `addError(sentinel error, msg string)`:
```go
func (c *Compiler) addError(sentinel error, msg string) {
    if len(c.errors) > 0 && errors.Is(c.errors[len(c.errors)-1], ErrMaxErrors) {
        return
    }
    c.errors = append(c.errors, fmt.Errorf("%w: %s", sentinel, msg))
    if len(c.errors) >= c.maxErrors {
        c.errors = append(c.errors, fmt.Errorf("%w (limit %d)", ErrMaxErrors, c.maxErrors))
    }
}
```

5. Update every `c.addError("...")` call site in compiler.go to pass the appropriate sentinel as first argument. Map each call site to its sentinel:
   - "circular typedef" messages → ErrCircularTypedef
   - "circular dependency" / "uses" messages → ErrCircularUses
   - "augment" / target not found messages → ErrAugmentNotFound
   - "duplicate" identifier messages → ErrDuplicateIdent
   - "list" / "key" messages → ErrListMissingKey
   - "config" boundary messages → ErrConfigBoundary
   - "default" + invalid messages → ErrInvalidDefault
   - "mandatory" + "default" messages → ErrMandatoryDefault
   - "type" restriction / range / pattern messages → ErrTypeRestriction
   - "identityref" / "identity" base messages → ErrIdentityrefBase
   - "xpath" / "must" / "when" syntax messages → ErrXPathSyntax
   - "compilation stopped" is only emitted by addError itself (ErrMaxErrors sentinel)

6. Replace the final error return in Compile() — wherever `strings.Join(c.errors, ...)` is used — with `errors.Join(c.errors...)`. Remove the `strings` import if it is no longer used elsewhere.

Do NOT change the message text of any addError call — only add the sentinel as first argument. The message text in the `%s` part is unchanged and still appears in err.Error() output.
  </action>
