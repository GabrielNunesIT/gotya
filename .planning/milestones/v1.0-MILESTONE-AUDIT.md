### Gaps (2)

**1. TEST-03 — Sentinel assertion migration incomplete**
- **File:** `compiler/compiler_test.go`
- **Found:** 21 `assert.Contains(err.Error(), "...")` calls, 0 `assert.ErrorIs` / `errors.Is` calls
- **Claimed by Phase 2 SUMMARY:** migration to `errors.Is` completed, grep showed 0 contains calls
- **Impact:** Sentinel error contract (`ErrCircularTypedef`, `ErrAugmentNotFound`, etc.) is declared and wired correctly in the compiler, but no test verifies it holds. A future refactor that removes `%w` wrapping would not be caught.
- **Severity:** major

**2. API-02 — Compile() multi-module diagnostic loss**
- **File:** `gotya.go` line 134
- **Found:** `return nil, fmt.Errorf("compile module %s: %w", mod.Name(), err)` inside the module loop exits on first error, discarding remaining modules
- **Impact:** Callers compiling `[]*ASTModule` with 2+ modules only receive errors from the first failing module. Subsequent module errors are silently dropped.
- **Severity:** minor (single-module use case works; multi-module is uncommon at v1)

## Tech Debt

**Phase 5 — API-03 design note:**
`Module.Schema()` returns `*schema.Module` directly. Callers who store the return value must import `github.com/gotya/gotya/schema`. This was an explicit design decision in Phase 5 SUMMARY ("Schema accessor pattern: legitimate callers need the schema for generators"). Full opaqueness was not the goal; clean accessor was. Not a bug.
